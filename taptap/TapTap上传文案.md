## 六、详细特色

- **轮回镜推演**：1 点开一场模拟，一年一行文字自动刷屏（暂停/缓/快/跳过四档），看另一世的自己修炼、游历、渡劫、陨落
- **造化继承**：模拟死亡后三选一（烙印升级后四选二）——继承修为、功法、法宝、寿数、道果、气运……把镜中收获带回家
- **宿敌系统**：每世随机一名血仇大敌，打不过会被一掌拍死；变强后反杀夺其招式，更强的幕后之敌接棒，从金丹一路杀到道祖
- **山河换幕（新）**：斩杀宿敌后山河换幕，地区循环推进、地图程序化重织——五套地域风貌（东境青云/西漠黄沙等）各有节点布局，越走越远
- **人脉好感（新）**：玄诚长老、胡掌柜、道侣三张人物卡，好感条与档次实时可查；赠礼结交——长老提携宗门任务收益，掌柜给你丹价折扣
- **抉择弹层（新）**：修炼先选闭关苦修或冲击破境，山河图点节点先确认前往；事件抉择放大纵排、逐项标注效果摘要，每一步都心里有数
- **现实经营**：时间只在操作时流逝——闭关修炼、突破境界、坊市交易（丹药阁/藏经阁/点数兑换三页签）、佩戴法宝、结缘道侣
- **山河图志**：世界大地图六大地点（青云宗/临仙坊市/落霞秘境/清源洞府/荒骨战场/天雷峰），赶路探索、拜入宗门攒贡献、秘境远征步步为营
- **四时洞天**：清晨白昼黄昏夜晚轮转，晴云雨雾灵潮变幻——洞府三大设施（聚灵阵/灵田/丹房）升级经营，收成与机缘随天气起伏
- **法宝装备位**：8 件法宝至多佩戴 3 件全额生效，行囊三页签一键装备卸下
- **轮回烙印**：道韵购买代代相传的永久强化，还有 15 档境界称号随最高成就进阶佩戴
- **33 种天赋 / 30 项成就 / 30 余种游历事件**：从"灵光初绽"到"混沌道体""雷帝转世"，每世开局都是新构建

## 七、操作说明

**手机 / 触屏**：全程点按即可玩——底栏按钮（开始模拟/修炼/山河图/坊市/行囊/人物/角色/寻仇）、模拟顶栏速度键（暂停/缓/快/跳过）、地图节点与面板按钮全部直接点击；修炼会先弹「闭关苦修/冲击破境」抉择层，山河图点节点先弹「前往」确认层，Esc 或「返回」即可收起。

**电脑（可选快捷键）**：

| 输入 | 功能 |
|------|------|
| 鼠标点击 | 一切按钮 |
| 空格 | 模拟中 暂停/继续 |
| 1 / 2 / 3 | 模拟速度：缓 / 快 / 跳过 |
| M | 打开山河图（世界地图） |
| C | 打开角色面板 |
| Esc | 先关弹层，再退界面 |
