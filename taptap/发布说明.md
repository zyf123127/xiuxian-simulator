## 上次更新内容（v1.7.0「商途幻境」）

- **文字清晰度二次修复**：全部文本绘制坐标取整（消除小数坐标亚像素渲染的笔画发虚）；
  wasm 侧改开 `high_dpi` 原生分辨率栅格化文字，并移植字形图集封顶补丁
  （按设备 GPU 上限封顶、触顶原地重置、丢字即重栅格化，规避真机黑块风险）；
  canvas 移除 `pixelated`——渲染分辨率=CSS×dpr 恰为物理像素 1:1，文字随屏清晰
- **点数经济重构**：法宝可献祭换模拟点（8 件法宝按强弱定价 2~15 点，永久失去，
  行囊内二次确认，已装备的一并卸下）；灵石兑点维持境界指数涨价；
  **死档机制**：点数不够模拟、灵石不够兑换、又无法宝可献祭时判定「山穷水尽」，
  底栏「开始模拟」变为「山穷水尽 · 观看广告」
- **轮回商阁·幻境广告**：死档救急出口——观看 5 秒幻境广告（创意按观看次数轮换：
  琼华仙丹/青云宗招生/轮回镜保养指南），看完领 2 枚模拟点，放弃无奖励；
  累计观看次数入存档
- **AI 立绘管线**（桌面版）：`assets/portraits/` 放入 AI 生成的立绘 PNG
  （境界四档 + 长老/掌柜）即自动替代内置像素立绘，缺失静默回退；
  生成提示词与风格规范见仓库 `docs/portrait_prompts.md`（H5 版暂用像素立绘）
- 存档新增 adw 键（广告观看次数），缺失键自动补默认值，**旧档完全兼容**

## H5 更新包说明

- **存档**：与首包一致——进度保存于浏览器 localStorage（键 `xiuxian_save`），
  与桌面版存档同格式；**属设备本机存储——换设备、清浏览器/TapTap 客户端数据后
  存档会丢失**；桌面版存档（xiuxian_save.txt）与 H5 存档不互通；跨设备云存档需接
  平台账号 SDK，暂不支持
- **缓存穿透**：index.html 中 bundle/wasm URL 均带 `?v=1.7.0`，覆盖上传后
  WebView 强制拉取新包
- **高分屏策略（本次升级）**：wasm 侧开启 macroquad `high_dpi`，渲染分辨率=
  CSS×dpr（手机上即原生像素），文字与 UI 全程原生栅格化；字形图集带设备上限
  封顶补丁防真机黑块；AI 立绘覆盖为桌面专属，H5 暂用像素立绘
- **加载体验**：加载层分阶段提示、12 秒超时可点击重试、无 WebGL/WebAssembly 设备
  给出中文诊断、WebGL 上下文丢失自动整页重载（存档不丢）；wasm 约 1.5MB

## 重新构建 / 发版流程

- 桌面版：`cargo build --release`
- H5 一键：`build_web.bat`（wasm 编译 → 复制 wasm **与 index.html** 到 web/ 与
  taptap_h5/ → 三件套断言 → 重打包 taptap_verify.zip）；改源码后必须重跑
- ZIP 结构核验：`python tools/verify_taptap_zip.py`（断言恰 3 条、`?v=1.7.0`、
  wasm 含 xx_storage 存档导出）
- 截图：GF_CLEAN=1 GF_DEBUG=1 桌面冒烟 56 张（1920×1080）→ 挑图复制
  `taptap/实机截图_H5/`；宣传图/图标 `python tools/make_promo_icon.py`
  （注：该工具按 1280×720 镜头裁切，镜头升 1920×1080 后重生成需先适配裁切参数）
- 文案改动后必须 `python tools/make_font.py` 重建字体子集并重新构建双端
  （本次已跑：1632 字符 428KB，全量扫描 0 缺字）
