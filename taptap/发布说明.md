## H5 更新包说明

- **存档**：与首包一致——进度保存于浏览器 localStorage（键 `xiuxian_save`），
  与桌面版存档同格式；**属设备本机存储——换设备、清浏览器/TapTap 客户端数据后
  存档会丢失**；桌面版存档（xiuxian_save.txt）与 H5 存档不互通；跨设备云存档需接
  平台账号 SDK，暂不支持
- **缓存穿透**：index.html 中 bundle/wasm URL 均带 `?v=1.8.0`，覆盖上传后
  WebView 强制拉取新包
- **高分屏策略**：wasm 侧开启 macroquad `high_dpi`，渲染分辨率=
  CSS×dpr（手机上即原生像素），文字与 UI 全程原生栅格化；字形图集带设备上限
  封顶补丁防真机黑块；AI 立绘覆盖为桌面专属，H5 暂用像素立绘
- **加载体验**：加载层分阶段提示、12 秒超时可点击重试、无 WebGL/WebAssembly 设备
  给出中文诊断、WebGL 上下文丢失自动整页重载（存档不丢）；wasm 约 1.5MB

## 重新构建 / 发版流程

- 桌面版：`cargo build --release`
- H5 一键：`build_web.bat`（wasm 编译 → 复制 wasm **与 index.html** 到 web/ 与
  taptap_h5/ → 三件套断言 → 重打包 taptap_verify.zip）；改源码后必须重跑
- ZIP 结构核验：`python tools/verify_taptap_zip.py`（断言恰 3 条、`?v=1.8.0`、
  wasm 含 xx_storage 存档导出）
- 截图：GF_CLEAN=1 GF_DEBUG=1 桌面冒烟 63 张（1920×1080）→ 挑图复制
  `taptap/实机截图_H5/`；宣传图/图标 `python tools/make_promo_icon.py`
  （注：该工具按 1280×720 镜头裁切，镜头升 1920×1080 后重生成需先适配裁切参数）
- 文案改动后必须 `python tools/make_font.py` 重建字体子集并重新构建双端
  （本次已跑：1697 字符 446KB，新字形「醉/宁/炼/鉴/酬」等全部入集）
