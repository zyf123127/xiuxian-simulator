# 凡人修仙·轮回模拟器 H5 发布说明

## 版本对照

- **对外首包版本：1.5.0**（TapTap 首次上架，更新日志一次性覆盖内部 v1.0.0 ~ v1.5.0 全部内容）
- 内部 Cargo 版本与 index.html 的 `GAME_VER` 缓存穿透号同步为 1.5.0；后续每次发版两处必须同升

## 本次上架内容（v1.5.0「四时洞天」重点）

- **洞府经营**：清源洞府三大设施升级——聚灵阵（闭关修炼效率最高 ×1.5）、
  灵田（每载自动产出灵石，收成随天气起伏）、丹房（坊市购丹最低七折）；
  升级消耗灵石与宗门贡献
- **四时天气**：清晨/白昼/黄昏/夜晚随推岁轮转，晴/云/雨/雾/灵潮按转移矩阵演化；
  山河图志整幅时段天气叠色，新增水面波光、飞鸟、洞府炊烟、路线高亮；
  闭关修炼、宗门任务、秘境远征抉择、灵田收成按天气 × 地点倍率浮动，
  灵潮时段天地灵机暴涨
- **法宝装备位**：8 件法宝至多佩戴 3 件全额生效，未装备仍按三成灵性计；
  角色面板点击装备/卸下，行囊标注装备态
- **修士立绘四档**：凡人/道基/紫府/真仙随最高境界进阶，高档自带背光与仙环
- **角色面板三页签**：总览 / 法宝 / 成就·称号——30 项成就带实时进度条，
  15 档境界称号可佩戴并显示于主界面
- **新信箱相机**：桌面 1280×720 显示恒等；为 H5 任意屏比例等比适配打底

## H5 首包说明

- **存档**：进度保存于浏览器 localStorage（键 `xiuxian_save`），与桌面版存档同格式；
  **属设备本机存储——换设备、清浏览器/TapTap 客户端数据后存档会丢失**；
  桌面版存档（xiuxian_save.txt）与 H5 存档不互通；跨设备云存档需接平台账号 SDK，暂不支持
- **缓存穿透**：index.html 中 bundle/wasm URL 均带 `?v=1.5.0`，每次发版必改 `GAME_VER`
- **加载体验**：加载层分阶段提示、12 秒超时可点击重试、无 WebGL/WebAssembly 设备
  给出中文诊断而非白屏、WebGL 上下文丢失后自动整页重载（存档不丢）
- **竖持适配**：手机竖持时整页旋转 90° 强制横屏视野，游戏内信箱相机等比缩放

## 已知说明与真机首测项

- **真机首测**（首包未经真机验证，上架后第一时间过一遍）：
  加载时长（wasm 约 1.4MB）、中文渲染完整性、触控点按全流程、
  WebAudio 音频是否出声（无声先查系统 WebView 硬件加速）
- **渡劫/秘境演出**：模拟跳过档一闪而过，建议新玩家用「缓」速看雷劫演出
- 角色面板四维行右侧的资质词沿用 v1.4.0 画法（各属性行均显示灵根资质词），
  属历史观感问题非本版引入，后续版本统一
- wasm 下 `std::fs` 为空操作（GF_DEBUG 截图/GF_CLEAN 删档仅桌面有效），符合预期

## 上传包

- `taptap/taptap_verify.zip`：ZIP 根目录一层 `taptap_h5/`（index.html + mq_js_bundle.js +
  xiuxian.wasm），条目 `/` 分隔，已用 Python zipfile 打包并核验三条目
- 解压验证目录：`taptap/taptap_verify/`（本地 `python -m http.server` 验证用，勿用 file://）

## 重新构建 / 发版流程

- 桌面版：`cargo build --release`
- H5 一键：`build_web.bat`（wasm 编译 → 复制到 web/ 与 taptap_h5/ → 三件套断言 →
  重打包 taptap_verify.zip）；改源码后必须重跑，保持包与代码同步
- ZIP 结构核验：`python tools/verify_taptap_zip.py`
- 截图/宣传图/图标再生成：GF_CLEAN=1 GF_DEBUG=1 桌面冒烟 42 张 → 挑图复制
  `taptap/实机截图_H5/`；`python tools/make_promo_icon.py`
- 文案改动后必须 `python tools/make_font.py` 重建字体子集并重新构建双端
