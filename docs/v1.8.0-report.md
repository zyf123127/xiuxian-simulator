## 四、设计与平衡要点

- **一域一格、数值克制**：五域各只强化一个维度（任务 1.20 / 远征 1.25 / 闭关 1.15 / 奇遇 1.20），仅南疆瘴林以 +0.08 远征风险换 1.20 远征收益——风险收益明码；换域探索由初至赏格阶梯（30/2000→260/80000，尾档约 4.3 倍于首档）驱动，`region_visited` 跨世持久使其成为多周目收集目标。
- **新 NPC 补现实侧短板**：大师姐管「破境成功率」（最高 +5%，温和不破防）、醉道人管「每载修炼」（最高 ×1.15）；事件门槛好感 70 且**抉择即消耗**（npc_ev 跨世标记）——单次剧情体验、防反复刷事件；赠礼价随档上涨（500×(1+档)）自然收敛无限送礼。
- **炼化的取舍**：不可逆献祭一件法宝换目标 +8%/级（顶 +3）；与 v1.7.0「献祭得点」经济正面竞争（炼化保值 vs 献祭换点），徽标与感知函数保证面板即时反映。
- **防呆与防穿透**：大额功法求购二次确认（常态钮不遮价）；炼化选材互斥态、再点取消、点外取消；献祭/炼化互斥清态；rmodal 模态独占期间弹层热键全失效＋Esc 首位吞＋C/M 双守卫，事件卡不会被底层 UI 穿透。
