## 四、设计与平衡要点

1. **平衡常量集中化**：9 个常量集中在 `src/data.rs:1718-1726`（远征链长/修为%/灵石基准/贡献、坊市折扣、洞府倍率、天雷峰加成），便于后续调参。
2. **地点收益构成迁址决策**：洞府闭关 +25% 修行提速 vs 赶路每次 1 载；坊市九折鼓励「回城买药」；天雷峰把「渡劫前移动」变成战术选择。三者均为地点条件生效而非全局（2.2 表），避免数值膨胀。
3. **远征的风险曲线**：先耗时后判定（途中寿尽即终局结算，`src/world.rs:63-78` 注释「旅途/秘境无养伤之地，不减 injured」）；激进/谨慎 ±10%/×1.5/×0.6 形成期望对称但方差不同的抉择；「收手归返」不耗时，鼓励「见好就收」；远征中锁场景出口（P5）防止中途读档式套利。
4. **宗门经济曲线**：任务贡献线性 20+8r，商品定价 60..420（数据表 `src/data.rs:1631`），灵石收益 300×(1+r)^1.6 指数增长；高阶商品（八灵尺/混沌天帝诀）设元婴期门槛，防低境界速刷。
5. **存档设计**：会话状态（选中节点/远征进度/商店开合）不进存档，只持久化 `Life.loc` 与 `Meta.sect_contrib`（`src/world.rs:5` 注释）；`sync_save` 保证「承接前缘」始终有档可承（`src/game.rs:876-878`）。
6. **借用规范贯彻**：新模块延续 game.rs 纪律——`self.life.as_mut()` 可变借用圈在小作用域、先取值后打日志（`src/world.rs:4` 注释，`spend_year` 返回 false 调用方必须立即 return，5 个调用点均遵守）。
7. **赶路任意直达 vs 路网仅视觉**（`src/data.rs:1603` 注释）：避免玩家被图论卡死，路网仅承担构图职能。
8. **美术复用现有先例**：底图生成沿用 `build_bg` 的确定性 PRNG 与逐列填充模式（`src/art.rs:290` 注释），不引入新依赖。
